# FORM House · Private Pilot Checklist
## Internal production sheet · October 2026

This checklist is private operating material. It is intentionally separate from the one-page partner concept.

## 1. Buyer / host

- [ ] Named decision-maker
- [ ] Property / organization
- [ ] Specific guest/resident problem
- [ ] Existing run/wellness programming understood
- [ ] Complementary reason for this morning is clear
- [ ] Who pays is explicit
- [ ] Fee / ticket / client-appreciation model chosen

## 2. Access

- [ ] Early access time confirmed
- [ ] Meeting point confirmed
- [ ] Belongings procedure confirmed
- [ ] Bathrooms confirmed
- [ ] Changing / showers confirmed, if offered
- [ ] Towels confirmed, if offered
- [ ] Seating / lounge area confirmed
- [ ] Parking / arrival instructions confirmed
- [ ] Pool / spa / recovery access is either explicitly agreed or omitted

## 3. Running

- [ ] Route(s) checked
- [ ] Distance / lane logic confirmed
- [ ] Named leader for every departure
- [ ] Pace / effort language is inclusive
- [ ] Turnaround or shorter option exists when appropriate
- [ ] Common return window is realistic
- [ ] Emergency contact / help procedure
- [ ] Weather decision owner and cutoff time
- [ ] Cancellation communication path

## 4. Food / hospitality

- [ ] Named food/service owner
- [ ] Menu and complete recipes/portions; use [the return-table brief](FORM_MORNING_RETURN_TABLE_2026-10.md)
- [ ] Carbohydrate and protein in each breakfast choice; actual product labels checked
- [ ] Sports dietitian review of the long-run menu and substitutions
- [ ] Dietary collection method
- [ ] Coffee / water / electrolytes
- [ ] Fresh orange juice / fruit; sodium-containing drink clearly labeled
- [ ] Drinks and easy food ready before the first return, independent of showers
- [ ] Allergen labels, cross-contact procedures and cold storage
- [ ] Service time
- [ ] Food remains available across plausible return spread
- [ ] Guests can stay without another required transaction
- [ ] Cleanup owner

## 5. Guest experience

- [ ] Capacity
- [ ] Invitation / reservation mechanism
- [ ] Arrival greeting owner
- [ ] Newcomer orientation
- [ ] Early finisher host remains on property
- [ ] Breakfast-only policy decided
- [ ] Finish / goodbye experience
- [ ] Contact for guest questions

## 6. Photography / media

- [ ] Is photography part of the scope?
- [ ] Separate photographer if run leadership requires full attention
- [ ] Participant permission language
- [ ] No-photo option
- [ ] Property usage rights
- [ ] FORM usage rights
- [ ] Deliverables / selection / edit / delivery date if commissioned

## 8. Go / revise / park gate

### Continue
- [ ] Named buyer / host
- [ ] Access path real
- [ ] Food/service owner named
- [ ] Direct costs estimated from real information
- [ ] Break-even is plausible at supported capacity
- [ ] Responsibilities written
- [ ] Experience adds something the host actually values

### Revise
Use when the buyer need is real but distance, schedule, food, scope or staffing does not fit.

### Park
Use when there is no buyer, no access, unrealistic economics, undefined volunteer labor or only vague “exposure.”

## 9. Closeout

Within 24 hours record:

**Arrived** — how did arrival actually work?  
**Returned** — did the routes / timing converge as intended?  
**Dwell** — did people stay, and what did they do?  
**Friction** — what made the morning harder than it should have been?  
**Worked** — what deserves to survive into another version?

Also record:
- actual direct costs;
- actual Brice time;
- guest count;
- no-shows / cancellations;
- host reaction;
- guest requests for another;
- whether there was a concrete commercial next step.

Do not infer recurring demand from enjoyment alone.
