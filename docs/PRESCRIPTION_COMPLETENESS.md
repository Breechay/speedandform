## 1 · Four sessions have no work target at all

These are the ones a coach genuinely has to answer. The athlete is told a
structure and not how hard to run it.

| | | |
|---|---|---|
| **W3 Hills + strides** | `8 × 12s → 4 × 20s` | No pace, no effort, no gradient. A twelve-second hill has no pace, so this wants an effort or a description — and the strides want a different one. |
| **W6 The Blind Mile** | `2 mi` | The name says the whole idea is running blind, so a pace band would defeat it. But *nothing* is stored: no effort, no instruction, no rule. The cell reads `2 mi` and the athlete cannot know what the session is. |
| **W9 VO₂ intervals** | `5 × 3 min / 2:30 jog` | No target. VO₂ implies faster than threshold and the plan never says how much. |
| **W13 VO₂ touch** | `3 × 2 min → 4 × 20s` | Same. |

## 2 · Every long run has no warm-up or cool-down — and correctly so

Nine sessions. A long run warms itself up over its first miles; typing
`WU 20` in front of a fourteen-miler would be inventing a session inside a
session. **Not a gap. No action.**

The same is true of `W1 3 to 6 × 1 km`, which also shows no recovery — that
one *is* a gap, because a kilometre repetition without a stated recovery is
genuinely ambiguous.
