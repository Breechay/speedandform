# Tone — Today is the app

The site and the app share a world. They do not share a voice.

**Site = understanding.** Philosophical, structured, timeless. *Run the effort. Let the pace appear.*

**App = action.** Short, physical, immediate. *Run steady.*

Anything from the site must be compressed before it enters the app. If it cannot be read in under one second while moving, it belongs on the site.

## Approved microcopy ceiling

Observational. Not emotional. Never hype, never praise, never speeches.

- “Held.” / “In.” / “Closed.” / “Logged.”
- “That’s enough.” / “Done. Let it land.”
- “Back tomorrow.” / “Keep the week intact.”

FILE SESSION is the verb. SESSION DETAILS is secondary. Edit is only on the placard.
