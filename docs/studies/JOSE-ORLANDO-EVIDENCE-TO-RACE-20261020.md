## Decision state for each idea
**Proposed → Evaluated → Adopted / Revised / Parked / Rejected → Implemented → Observed.**

For an **adopted** idea record: goal served, direct evidence, coach rationale, exact intervention, owner, session/race-week destination, expected signal, downside, stop/change rule in **private** notes, and date of next review. For **rejected or parked** ideas, retain a concise reason so the same idea does not reappear as new.

A published session is the athlete's single definite instruction. Evaluate fatigue and readiness privately; if needed, the coach changes the actual prescription before the workout. No "if absorbed" or "if recovered" clauses in athlete-facing copy.
