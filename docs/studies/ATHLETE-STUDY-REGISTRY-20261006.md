This is an operating registry, not a public directory.

Read first: [Athlete study operating model](ATHLETE-STUDY-OPERATING-MODEL-20261006.md).

## Rule

A new coached athlete is not fully onboarded until the system has:
1. an athlete record;
2. a current goal / phase;
3. a one-sentence study question;
4. a named weekly priority;
5. a next gate;
6. running / strength authority identified.

The study may stay tiny. Public publication is a separate decision.

## Backfill rule

Do not create fifteen decorative pages to make the registry look complete.

Backfill a concise study file when:
- the next meaningful evidence arrives;
- a phase is being authored;
- a decision would otherwise be lost across chats;
- running + strength interactions need a shared read.

## Promotion

A mini / athlete-record study becomes a feature study only when evidence, permission and teaching value justify it.

The athlete does not earn a larger page by suffering more or performing better.
