# FORM athlete-study operating model

Owner: Brice Ikouebe  
Adopted: October 6, 2026  
Status: coaching-system canon.

## The default

**Every active coached athlete gets a study record. Not every athlete gets a feature story.**

The study record is how FORM remembers the coaching question, the current prescription, what happened, what it cost, what the athlete reported, what else could explain it, and what the next useful decision is.

A study can stay small for its entire life. The purpose is better coaching and transferable learning, not producing a dramatic public page for every person.

## Three study levels

### 1 · Athlete study record · default

Every athlete gets this.

Minimum contents:
- goal / target event or physique direction;
- current phase;
- one current coaching question;
- running / strength authorities;
- current weekly priority;
- latest useful evidence;
- next gate;
- known constraints and competing load;
- what would change the current interpretation.

This can live as a concise dated Markdown record plus canonical Athlete System data. No public page is required.

### 2 · Mini study · common

Use when an athlete has a useful question worth following but does not need a large editorial treatment.

A mini study should be direct:
- **Question**
- **Why now**
- **Current plan**
- **What we are watching**
- **Latest read**
- **Next decision**

One simple page is enough when a page is useful. It can be unlisted/noindex when public-study permission is absent or when the material is primarily operational.

Examples: Devin's body-composition / strength consistency work, Anthony's current Race Pace Durability application, a short return-to-running case, or a six-week FORM + FORGE integration.

### 3 · Feature / connected study · selective

Use only when the case deserves the extra surface.

Good reasons:
- unusually strong longitudinal compliance;
- multiple clean evidence points;
- an interesting question that can teach other athletes;
- public permission;
- a meaningful race or phase endpoint;
- enough contrast or history to justify explanation.

Speed That Endures, The Two Curves and The Durable Frame can carry richer presentation because the evidence and narrative support it. Page grandeur is not a marker of coaching importance.

## Authority

**FORM owns running prescription and running evidence.**  
**FORGE owns strength prescription and strength evidence.**  
**The athlete study interprets the interaction.**

A study does not become a second plan.

When running and strength coexist:
- count hard lower-body lifting, HYROX and other demanding work as real load;
- preserve each system's actual prescription;
- change the support system before stealing from the week's primary question;
- do not infer a strength diagnosis from a hard run or a running diagnosis from a hard lift.

## The weekly hierarchy

Every week should make clear which session is asking the main question.

### Primary question

For the current running studies, this is often Tuesday.

The primary session is not automatically the hardest session. It is the session whose answer most affects the next decision.

**Protect the primary question.**

The day before it should not acquire:
- bonus mileage;
- surprise intervals;
- a fast finish;
- hard lower-body strength;
- an unscheduled race / simulation;
- a make-up workout.

New athletes should be taught this explicitly rather than expected to infer it.

### Support slot

**Thursday is earned, not owed.**

Thursday means aerobic / mechanical support for the week. Its form can be:
- threshold;
- faster aerobic work;
- strides;
- easy running;
- recovery;
- rest.

Use the more demanding option only when the primary session was controlled and recovery is normal. If Tuesday or another primary demand was costly, Thursday gets cheaper first.

For hybrid athletes, hard HYROX or lower-body strength can consume the Thursday quality budget.

This is not a universal Tuesday/Thursday calendar rule. It is a priority rule: **the support session serves the primary question, not the other way around.**

### Long run / second question

Saturday or the long run builds the durability floor and, later, may ask a separate late-access question.

Do not automatically stack a large Tuesday ask, a full Thursday quality session and a fast-finish long run just because each workout is useful in isolation.

## The observation grammar

Use the same grammar across running and strength athletes:

**Purpose → Prediction → Execution → Cost → Limiter → Recovery → Competing explanations → Confidence → Next smallest useful test**

### Purpose
What capability is this session supposed to support?

### Prediction
What do we expect if the current interpretation is roughly right?

### Execution
What was actually done? Preserve deviations rather than smoothing them into the prescription.

### Cost
How hard was it relative to its job?

### Limiter
Legs, breathing, mechanics, attention, pain, fueling, conditions, load, equipment, something else, or unclear?

### Recovery
What happened later that day, the next morning and before the next important session?

### Competing explanations
Keep at least one alternative alive when causation is uncertain.

### Confidence
Low / moderate / high. Confidence belongs to the interpretation, not to the athlete.

### Next smallest useful test
Change the least necessary to improve training or distinguish the live interpretations.

## Common measures, different prescriptions

The system should be comparable without becoming one-size-fits-all.

### Running
- prescribed vs actual work;
- pacing integrity;
- separate leg / breathing / whole-body effort when useful;
- reserve;
- interruptions / rescue surges;
- conditions and preparation;
- 24–48 h recovery;
- effect on the next key session.

### Strength
- exercise;
- load;
- reps;
- RIR / RPE;
- movement quality / ROM when relevant;
- discomfort;
- completion;
- progression from comparable exposures;
- interference with running or another primary goal.

### Physique / body-composition studies
Use only evidence the athlete actually supplies:
- comparable bodyweight trend;
- waist;
- photos;
- clothing / silhouette observations;
- adherence;
- performance preservation.

Do not invent body-fat percentages or convert one photo into a physiological conclusion.

## Athlete report

Athletes are valuable observers of what they experience.

Treat:
- "my legs get heavy when I restart,"
- "I settle after ten minutes,"
- "this movement feels unstable,"
- "Thursday left me flat on Saturday"

as evidence worth preserving.

Do not automatically convert the athlete's explanation into the mechanism.

**Athlete report = evidence.  
Athlete report ≠ diagnosis.**

Engagement is also evidence, but **engagement ≠ readiness**. When an athlete calls a conditional workout a challenge, keep the condition visible.

## Progress

Progress can be:
- more useful duration;
- lower cost at the same task;
- better pacing or movement control;
- more reserve;
- normal recovery after a formerly costly dose;
- repeatability;
- late access after prior running;
- more load / reps with the same form and RIR;
- better coexistence between running and strength.

Completion of a harder session is not automatically progress.

## No debt

There are no catch-up surges, make-up miles, bonus sets or replacement workouts owed because a support session was shortened or skipped.

Missed evidence is missing evidence. It is not a debt the athlete has to repay.

## New-athlete onboarding

Before the first meaningful training week, teach these rules in plain language:

1. **Know the session that matters most this week.**
2. **Protect the day before it.**
3. **Do not add work because you feel good.**
4. **Thursday / secondary quality is earned by recovery.**
5. **Tell me what limited you, not only whether you finished.**
6. **A modified or skipped support session does not need to be made up.**
7. **The plan can change when the evidence changes; the goal does not change every day.**

## Public-study gate

Before anything becomes a public study page:
- public use is permitted;
- private medical / identifying details are removed;
- the case has enough evidence to say something useful;
- source facts and coach interpretation are separated;
- scheduled work is not written as completed work;
- the page has a clear reason to exist.

A mini study may remain private or unlisted indefinitely.

## Promotion rule

A small study can become a feature study when the evidence earns it.

A feature study can also become quiet again. Editorial prominence is not a training reward.

## Review cadence

For active athletes:
- update after meaningful key evidence;
- review the whole week before changing a single session;
- at phase gates, audit running + strength + other quality load together;
- preserve superseded decisions as history;
- keep canonical plan/session data separate from study interpretation.
