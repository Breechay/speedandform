# Tinius · The Durable Frame · FORM Human Performance Study 004

Owner: Brice Ikouebe  
Opened: 2026-10-05  
Public case-study consent: confirmed by coach from the athlete before publication.

## Question

**Can Tinius rebuild a sharper, more muscular athletic frame while his FORM running development continues — without strength work stealing from the running?**

## Why this athlete

Tinius is unusually consistent when a prescription is explicit. The coaching problem is therefore not motivation; it is allocation. If the plan gives him optional extra work, he tends to do it. The program should use clear limits, fixed days and one progression rule.

His existing FORM running block remains the running authority. The current block is Race Pace Durability, authored in kilometers. FORGE must fit around that work rather than independently adding lower-body stress.

## Current direction

The physique target is the existing Breechay Sculpt canon translated to this athlete:
- broader shoulders / upper frame;
- stronger upper back and upper chest;
- sharper waist and trunk;
- useful posterior-chain and unilateral leg strength;
- preserve or improve the endurance qualities already present.

This is not a bodybuilding-only block and not a second running plan.

## Phase 01 · six-week integration

Working structure:
- **Tuesday after FORM quality · Frame A** — upper-dominant; shoulders, upper chest, back; minimal leg fatigue.
- **Thursday after FORM quality · Lower + Core** — unilateral leg work, posterior chain, calf/foot support and trunk stability; volume capped so Saturday remains available.
- **Sunday · Frame B** — upper-dominant; back, shoulders, arms, chest; no lower-body debt after Saturday.

Progression:
- W1 Establish
- W2 Repeat
- W3 Build
- W4 Hold
- W5 Absorb
- W6 Close / compare

Do not add a fourth strength day. Do not add bonus sets because a session felt easy.

## Equipment gate

Athlete currently reports:
- yoga mat;
- adjustable kettlebell;
- small barbell;
- several plates / weights.

Exact kettlebell range and total barbell loading are still pending. The movement slots can be authored now, but final exercise selection and rep/loading strategy should not pretend unavailable loads exist.

## Progression rule

If every prescribed set reaches the top of its rep range with clean form and roughly two reps still available, add the smallest available load next exposure. When load cannot increase, progress only through an authored rep/tempo/leverage change. Do not solve limited equipment by adding random exercises.

## Measures

Keep running and strength evidence separate:
- FORM: running completion, pace/effort context, key-session response, long-run response.
- FORGE: exercise, load, reps, RIR/form notes, session completion.
- Study: waist / photos if athlete supplies comparable measurements, bodyweight context if useful, subjective athletic feel, and whether strength interferes with or supports running.

## Integration rule

**FORM runs. FORGE lifts. Study 004 interprets the interaction.**

## Next gate

Receive the exact kettlebell and barbell/plate weights, then freeze the Week 1 exercise map and publish the six-week FORGE delivery version.
