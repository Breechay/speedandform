## Question

**Can Devin become visibly leaner while keeping his strength work normal and adding enough easy aerobic work to support the cut without shrinking the frame or turning the runs into another performance contest?**

## Why this is a mini study

The coaching question is useful, but it does not need a large editorial Labs treatment.

The existing unlisted Week 01 page is a prior implementation artifact: four lifts, three easy 35-minute runs and practical food structure. It is evidence of the coaching direction, not an immutable schedule or a public transformation claim.

This study exists to keep the coaching logic and evidence in one place as the schedule changes.

## Authorities

- **Coach-managed strength:** current strength prescription and session logistics.
- **FORM running principle:** easy aerobic support only unless Brice explicitly authors another running purpose.
- **Study:** interprets adherence, body-composition direction, strength preservation, easy-running response and recovery.

Do not infer a running race program from this study.

## Current coaching question

The cut only works for the stated goal if the frame and training quality remain available.

We therefore care about:
- strength sessions still feeling normal;
- easy runs remaining genuinely easy;
- enough food/protein support to preserve useful training;
- body-composition evidence changing gradually;
- no compensatory extra cardio because a day felt good.

Fasting is not a score and longer is not automatically better. If a shorter eating window makes training or adequate intake worse, it has failed its support role.

## Weekly priority

This athlete does not inherit the runner-specific rule that Tuesday is always the primary session.

Instead:

1. **Name the week's primary strength sessions.**
2. Keep added running cheap enough that those sessions remain normal.
3. Do not add a harder run because an easy run felt good.
4. If recovery or strength quality falls, remove extra aerobic cost before escalating the cut.
5. A missed run is not debt.

## What we track

### Practice
- planned vs completed strength;
- planned vs completed easy running;
- schedule friction / missed sessions;
- unplanned extras.

### Capacity
- comparable exercise load + reps;
- RIR / movement quality where recorded;
- whether normal loads suddenly feel unusually costly;
- core / trunk control when it is part of the current work.

### Body / silhouette
Only when Devin supplies comparable evidence:
- morning bodyweight trend;
- waist;
- comparable photos;
- clothing / visual silhouette notes.

Do not invent body-fat percentage from photographs.

### Recovery
- soreness / fatigue that affects the next session;
- whether easy running changes leg quality;
- sleep / schedule context when it is clearly relevant.

## Latest known baseline

The existing Week 01 page used:
- four strength days;
- three 35-minute easy runs;
- easy effort defined by conversational running rather than pace or distance;
- simple repeatable food structure;
- morning weight checks and a weekly waist/photo comparison.

Treat those as a baseline structure, not a permanent prescription.

## Progress

Progress is not "more cardio" or "a longer fast."

Useful progress looks like:
- similar or better strength at a gradually leaner silhouette;
- easy running that remains low-cost;
- a week that becomes easier to repeat;
- better adherence without needing increasingly restrictive behavior.

## Next gate

At the next comparable check:
- compare recent strength loads/reps with the baseline;
- review how the added easy running affected legs and recovery;
- use only supplied comparable weight/waist/photo evidence;
- decide whether the aerobic dose stays, increases modestly, or gets cheaper.
