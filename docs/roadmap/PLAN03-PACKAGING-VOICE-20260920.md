# Plan 03 packaging + voice
## Marathon Durability / The Last 10K · September 20, 2026

This note governs public explanation after the method freeze. It does **not** change the training method.

## Audience comprehension standard

Use a fast 17-year-old runner as the comprehension test even though the actual Plan 03 buyer is an experienced marathon runner.

If that reader has to decode FORM vocabulary before understanding the point, the copy is too abstract.

## Public-language hierarchy

Plain first. Technical second.

### Marathon Durability

Primary idea:
> **You're already fast. Now make it last.**

Supporting idea:
> The pace is not the progression. The depth is.

Explain the week in human jobs:
- Tuesday · speed touch
- Thursday · support
- Saturday · key run

Technical terms such as specific reserve, ceiling, marathon rhythm and field-performance hypotheses can remain lower on the page where they add precision.

### The Last 10K

Primary question:
> **What happens when the easy miles run out?**

The study should read in this order:
1. the human question;
2. the shift — same useful pace, deeper in the run;
3. Orlando;
4. two quiet weeks;
5. Donna runway;
6. live record;
7. technical framework / hypotheses / falsification;
8. amendments.

Technical rigor stays available through disclosure. It should not be the first thing a skimming runner has to understand.

## Visual mental model

One dominant model wins:

**Move the target deeper.**

The green block represents the pace/capability we care about.
- earlier: it appears with less prior running;
- later: more running sits in front of it.

Use the Exposure Instrument rather than inventing multiple competing metaphors.

## Metaphors we did not literalize

Do **not** publish fake diagnostic meters such as:
- cardio 80% / leg stiffness 10%;
- quantified spring/recoil depletion without measured evidence;
- a “speed vault” score;
- a durability/readiness score.

Marathon fading is multifactorial. Plain copy may say that the legs can go heavy while breathing still feels controlled, but it must also leave room for fueling, pacing, heat, muscular/structural cost and mixed causes.

## Product-comparison rule

Do not claim all “traditional plans” only add junk mileage or separate speed from endurance.

Use the narrower framing:
> A common response to late fading is simply adding more mileage. More endurance can help. Plan 03 also trains where useful pace is still available.

No category straw man is required to explain FORM.

## Mobile rules

Marathon Durability:
- full matrix stays desktop;
- mobile builds week cards from the same table source;
- Saturday key run is visible first;
- Tuesday/Thursday live behind the disclosure.

The Last 10K:
- Donna runway becomes week cards on mobile;
- key Saturday work is visible in the card summary when available;
- technical hypotheses and failure tests are collapsible;
- floating Contents control provides return navigation.

No duplicate authored plan data should be maintained solely for mobile.

## Cream interruption

A single warm-paper summary block is allowed near the top of each page to break the dark field and pull the eye to the simplest explanation.

Do not turn the whole page into alternating cards.

## Header rule

Match Speed That Endures / Bridge:
- fixed translucent gradient;
- slight blur;
- no thin bottom border;
- content passes underneath rather than being cut by a bar.

## Do not reopen

Packaging may simplify words and reorder explanation. It does not change:
- Plan 03 programming;
- four study hypotheses;
- athlete-specific authority rules;
- the evidence grammar;
- the method freeze.
