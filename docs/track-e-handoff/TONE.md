# Tone — the dragon is silent

The site and the app share a world. They do not share a voice.

**Site = understanding.** Philosophical, structured, timeless.

**App = action.** Short, physical, immediate. If it cannot be read in under one second while moving, it belongs on the site.

## What this means for weather

The dragon does not speak. No caption. No “atmosphere.” No label. No legend.

Do not port:

| Site | App |
|---|---|
| *Every session is built for something.* | The disc already says the session. |
| `03 / THE INSTRUMENT` | Nothing. The screen is Today. |
| `FORM · iOS` | The wordmark is already FORM. |

FILE SESSION stays the verb. SESSION DETAILS stays secondary. The tab still opens the ivory placard.

## Track D already landed

Do not reintroduce receipt, evidence, claim, condition, dose, authored, band, classified, Program Director. VoiceOver stays filed / not filed / rest / no session.

If weather needs a VoiceOver string: nothing, or one word that is not a speech. Prefer nothing. Decorative. Hidden from VoiceOver unless the crop becomes an accidental button.
