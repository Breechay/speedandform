# Strength capability — direct path audit

SITE-002. Verified September 15, 2026 against production and `main`.

## The question the milestone asks

> Verify whether the current strength page answers a live client's question.

**It did not.** Not because it was wrong, but because it was a different kind of page than the milestone assumed.

## What `/strength.html` actually is

Title: *Structural Work*. It is a **method page**, and a good one: why structural work supports running, what it trains, the rib cage and pelvis material, cues, and links out to the durability routine, activation, mechanical fixes and mobility.

What it did **not** contain, before this change:

- any statement that coached strength exists as a service
- any scope or service boundary
- any pricing
- **any route to intake whatsoever** — no contact link, no inquiry path, nothing

Someone arriving from search looking for a strength coach could read the entire page, agree with all of it, and have no way to reach Brice.

## What already exists elsewhere

The milestone's definition of done says Brice confirms "the provisional local/remote pricing". **That pricing is already live and already his**, on the homepage intake:

- Run · $1,200 / 8 weeks
- **Run + Strength · $1,800 / 8 weeks** — "Everything in Run, plus strength programming and four coached gym sessions across eight weeks"
- a remote option

So strength is a defined, priced service with a working intake record. The dependency the milestone recorded was already satisfied; the gap was never pricing, it was that one page never pointed at the other.

## What changed

One block above the existing hub links, in the page's own type and spacing, with one divider owner:

> **WORKING TOGETHER**
> This page is the reasoning. If you want the structural work built around your actual running week rather than added on top of it, that is coaching, and it is the same intake as everything else.
> **WORK WITH BRICE →** → `/#begin`

Deliberately **no pricing and no scope is restated here.** Both live on the homepage, authored by Brice, and duplicating them creates two places to keep true. This page only has to make them reachable. Nothing about service boundaries was invented.

"Root remains Run Development" is preserved: the copy frames structural work as built around the running week, and routes to the same single intake rather than creating a separate strength funnel.

## Verified

Rendered at desktop width; the block sits between the closing line and the hub links without a doubled rule. `/#begin` is the same anchor `/labs/track/` and the Labs index use. No em dashes or British spelling introduced in copy.

## Left open, and genuinely Brice's

- Whether the strength offer should have its own page with scope and pricing, rather than living only as an option inside the homepage intake. That is a positioning decision, not a defect.
- Whether "local versus remote" needs to be explicit anywhere public. The homepage intake has a remote option; no page explains the difference.
