## App/console
Use current build and actual entry points. Inspect empty/loading/offline/error/saved/corrected/denied states.
Trace sign-in → identity/mode → today → details → file → confirmation → next; console → evidence → read → decision → delivery.
Data must agree. Uniform containers for equivalent roles, readable text, balanced placement, no gratuitous empty-state labels.
Do not render absence as deficiency; retain missing context when it prevents an incorrect decision.
Measured/reported/interpreted/decided distinctions survive visual cleanup.

Update roadmap; only call production verified after inspecting actual deployment.
