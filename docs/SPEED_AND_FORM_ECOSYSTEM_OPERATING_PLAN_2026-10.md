# Speed & Form — Ecosystem Operating Plan
## October 2026 · v1 · 2026-10-02

This is the operating plan for turning Speed & Form into one coherent practice across the public website, shared mornings, paid coaching, plans, studies, photography/archive and FORM.

It is intentionally a one-month development plan, not a one-week feature sprint. The purpose is to make the practice easier to discover, join, understand, hire and continue inside FORM without turning the website or app into generic fitness software.

## North star

**Coaching, living studies, shared mornings, photography and a beautiful archive are the center.**

Public loop:

**Show up → experience the practice → see the work → choose more structure if wanted → train through a plan or Run Development → preserve the history in FORM.**

The website is the public discovery and explanation layer. FORM is the living execution and continuity layer. They meet at shared practice, selected proof and published archive material.

## Operating rules

1. Build from real weekly practice, not competitor feature lists.
2. One primary action per public surface. Coaching bridges are quiet and contextual.
3. Free tools remain genuinely useful; they do not become disguised sales funnels.
4. No scarcity copy or transformation claims.
5. Dynamic numbers such as current roster size should not become permanent copy unless there is a maintained source.
6. Saturday long runs are occurrences, not a promised monthly cadence unless Brice explicitly adopts that cadence.
7. FORM owns living occurrences, RSVP/attendance, athlete execution and private history. The website owns public discovery and evergreen explanation.
8. Selected FORM photographs/studies can become public proof; the website should not duplicate the full archive.
9. Daily Brief reads and prioritizes canonical sources; it does not become a second source of truth.
10. Stop redesigning once a surface is coherent enough to use. Real participation, inquiries, coaching and publishing provide the next evidence.

# Four passes

## PASS 01 — Community + participation
Goal: make Thursday and Saturday easy to find, understand and join.

Public architecture:
- Keep /thursday as the live Thursday occurrence/detail surface.
- Create one clear parent community entry point. Preferred working route: /run-with-us.
- First inspect the existing Miami running/community surface; reuse or redirect rather than duplicate.
- Saturday is a scheduled occurrence, not a standing promise.

Parent page:
1. Hero — Run with us.
2. Thursday — Flamingo Park Track.
3. Saturday — long-run occurrence.
4. What happens / belonging.
5. Quiet path to plans/coaching.
6. From the practice / selected FORM connection.

Hero:
Run with us.
Thursday speedwork at Flamingo Park Track.
Saturday long runs when one is scheduled.
All levels. No pace required to arrive.

Thursday principles:
- short, faster running with enough recovery to do each repetition well;
- no specific pace required;
- Flamingo Park Track · Miami Beach;
- live occurrence is authoritative for exact time;
- confirm before traveling;
- all levels · run your own effort;
- “You can leave after the first rep. Finishing everything is not the price of belonging.”

Saturday:
Treat the supplied map posters as the beginning of a session-poster system:
**day/time → route → Workout Group → Easy Long Run Group → miles/km variants.**

Current example:
- Workout: 14 miles total; 11 easy around 7:20/mi; last 3 at 6:00–6:20/mi.
- Easy: 6–14 miles at 8:00/mi or slower.
- Metric companion exists.
- Exact prescription belongs to the occurrence; do not turn the example into a permanent weekly promise.

Unscheduled state: “No long run scheduled yet.”

Belonging:
01 · Run the session as written for your level/assignment.
02 · Rest fully when the session calls for recovery.
03 · No pace is required to arrive.
04 · Leave when you need to.

Community bridge:
“Want the rest of the week built around you?”
Some people start with the group and stay with the group. Some want a plan around the sessions. Some want the week fully individualized.
Run Development is eight weeks of coaching built around where you are and what you want to become capable of.
CTA: Ask about a Miami assessment.

Pass 01 finish:
- one obvious community entry;
- current Thursday details and confirmation warning;
- Saturday scheduled/unscheduled states;
- miles + metric poster treatment;
- community links to Plans + Run Development;
- clean mobile;
- no uncommitted cadence promise.

## PASS 03 — FORM ↔ website architecture
Goal: build the living product around what Brice actually opens every week.

Ownership:
- Athlete Week: FORM owns prescription/execution/history; website explains coaching.
- Thursday/Saturday: FORM owns occurrence, host, RSVP, attendance, Board and archive; website owns discovery/public live details.
- Photos: FORM owns Roll/cull/Nine/cover/publish state; website shows selected published proof.
- Development: FORM owns dossier/goal/blocks/key sessions/notes; website shows selected studies.
- Plans: FORM owns assignment/ownership/execution when entitled; website owns discovery/preview/purchase.
- Studies: private evidence/continuity in coaching systems; curated public study on web.
- Vault: FORM owns canonical reusable sessions; website exposes selected references.

Tier 1:
1. Week — individualized daily home; Thursday only when relevant.
2. Shared mornings / Collective — Thursday + Saturday as same hosted-occurrence model; RSVP separate from attendance; minimal Board; past mornings accessible.
3. Archive · Roll → Nine — private Roll; Keep/Maybe/Set aside; select/reorder; cover/crop; Cream/Dark; exact preview; publish/recovery; Instagram + website export.
4. Dossier + Development — goal poster; phase/focus; key sessions; block reviews; coach notes; visible development arc.
5. Coach basics — current athletes; quick actions; messages; plan assignment/adjustment; simple notes.

Tier 2:
- named-session Vault;
- published-album public preview;
- plan ownership for paid self-directed plans when entitlement is ready;
- shared-morning notification opt-in.

Wait:
feeds/follows/leaderboards; member-created runs; broad member DMs; public athlete dossiers/goals; generic social layer; automatic coaching interpretation presented as coach judgment; competitor-parity features.

Feature filter:
1. Will Brice open it most weeks to coach or document?
2. Does it improve a real morning, athlete relationship or photograph?
3. Does it make history more useful or beautiful?
4. Would the practice still want it if no competing app had it?

## PASS 04 — Consolidation + release
Goal: reach a clean stopping point and operate the system.

QA:
desktop/mobile; links; accessibility/tap targets; empty/scheduled states; SEO; stale dynamic claims; community details; inquiry path; FORM/public ownership boundaries.

Documentation:
current state; NOW/NEXT/LATER; dependencies; owner; completion evidence; deliberate deferrals; next review date.

Then stop ecosystem redesign for a period. Run Thursday. Host Saturday when useful. Coach. Photograph. Publish. Sell. Watch where people enter and what they choose.

# Daily Operating Brief integration

The Daily Brief remains the morning control surface, not a giant project manager.

Add an **ECOSYSTEM / COMPANY BUILD** block showing no more than four rows:
- Public practice — current Pass 01/02 item.
- FORM product — current Tier 1 item.
- Athlete/study — one current coaching-truth task.
- Commercial — one revenue/delivery loop.

Each row has: state; today’s next action; finish condition; owner.

Below:
- Waiting on — external dependencies only.
- Agent work — delegated work needing review.
- Shipped yesterday — maximum 3.
- Do not reopen — frozen decisions agents should not casually revisit.

Existing Training/Recovery, Money/Housing, Athletes/Coaching and Life sections remain. Company building does not erase recovery, cash protection or athlete delivery.

Daily selection rule:
A successful day advances:
1. one practice/product item;
2. one athlete/customer/revenue item;
3. one system/evidence item;
with a fourth only when necessary.

# Source-of-truth doctrine

Daily Brief = today’s instruction.
Console/roadmap = whole-company attention and milestone state.
Study = athlete/research narrative + selected evidence.
FORM Week/occurrences = prescription + execution.

No layer silently rewrites another.
