## Media library (key distinction)

| Folder | Holds |
|--------|--------|
| **SELECTS** | Best stills from a shoot |
| **LIBRARY** | Reusable clips — rain, steam, preparation, movement — inventory for future edits |
| **PROJECTS** | Exports when building FORM reels, Sunday films, profiles |

Think by **signal** (rain, preparation, communal energy), not by shoot date.

## Day-to-day

1. Before shoot → `/studio` → **Open Field Guide**
2. After cull → route to `~/Documents/FORM/` — stills to SELECTS, clips to LIBRARY, empty Downloads
3. Edit reel → pull from LIBRARY + export to PROJECTS

**Media root:** `~/Documents/FORM/` — not git. Repos hold docs and code only.

## Do not

- Link `/studio` from marketing unless you want discovery.
- Leave clips only in shoot folders if they'd work in a reel six months later — that's LIBRARY.
