## What it is

One scroll, fixed sidebar, six collapsible sections (1–6 keyboard shortcuts):

1. **The Map** — how perception manual, cinema doctrine, and studio relate
2. **Perception** — compressed doctrine + link to full manual
3. **Cinema** — When It Matters extracts inline
4. **Field Guide** — pre-shoot checklist, protocols (self, athletes, Hideout), eye training, culling
5. **File System** — drive folder structure, naming, archive logic
6. **Films** — watch list with context

Use **Field Guide** most often. Use **Perception** section for quick recall; open `/perception-manual` for full chapters.

## Day-to-day editing

1. Edit `studio.html` in Cursor (or paste into Claude — then copy back to repo file, not Downloads-only).
2. Commit + push to `main` → Netlify deploys.
