# FORM Long Run · Distance Owned

**Coach design · October 30, 2026. NOT an athlete publication.** This is the paired endurance lane alongside the 5K-led FORM Thursdays. Current versioned athlete plans, completed evidence, named exceptions and actual published Collective occurrences remain authoritative until individually changed by the signed-in coach.

## The decision

The group meets and starts easily together. The work is individualized: distance, pace and the final segment belong to each athlete's own week. Build toward a **10–14-mile established long run for non-marathon athletes** and a **12–16-mile FORM group segment for marathoners**, with separate race-specific extensions when a marathon plan genuinely warrants them. These are earned operating ranges, **not a ten-mile minimum for a new runner, returning athlete, or someone whose present plan is four to seven miles**. Coach determines the actual distance in advance; no athlete-facing “choose 10–16” or recovery-condition language.

For the faster cohort, **8:30–7:20/mi** is a broad *possible* aerobic range, not a safe universal pace prescription. Current Anthony and Jimmy long-run components start at **8:00/mi or slower**, and Simon's current easy long run starts around **7:55/mi or slower**. The upper end 7:20 can be a controlled progression or finish for a suitable athlete, not the default group start. The first two miles should be easy enough to converse, and each athlete's pace band is authored from actual capacity. Faster runners can circle back or loop; social cohesion should not turn a slower athlete's easy run into tempo.

**Do not impose both a new longest distance and a fast finish in the same week.** Thursday is already a substantial speed stimulus. In this lane, the main development variable is duration at controlled mechanics, with occasional paced finishes to test whether useful running remains available late. Mechanics are observed, not inferred from pace alone. Fueling/hydration for long efforts remains an individual coach decision.

## Session repertoire

1. **The Long Easy** — one continuous easy run. Full-distance consistency, economy and tissue exposure without another workout. The default after a demanding Thursday or in a cutback.
2. **Three Speeds** — first 2 mi intentionally easy, middle at normal aerobic pace, final 2–3 mi slightly quicker but below independently established marathon/half-marathon race pace. Pace changes are gradual, not a continuous race test.
3. **Fast Finish · Marathon** — first 70–80% easy, last 2–4 mi at that athlete's *verified* marathon-pace band. Principally for marathon-specific athletes with enough recent long-run volume. Not the default for a 5K athlete or a returning runner.
4. **Late Hold** — easy opening, then 2 × 2 mi controlled steady with 1 mi easy between. A later option for runners who have already handled uninterrupted long distances. This tests resettling and form, rather than a single hard final sprint.
5. **Negative Split · Easy** — easy first half and only a modestly quicker second half, both within the athlete's easy aerobic range. Useful for mixed groups because it creates a pacing skill without an extra hard session.
6. **Cutback / Race-adjacent** — shorter easy long run, with no fast finish. Keep an actual race and the immediate recovery period separate from the group's progression.

The menu is a Vault-style authoring vocabulary, **not a rotation enforced by the calendar**. Before a coach versions the next Saturday, compare the most recent Thursday execution, actual longest run in the preceding month, last seven days' running/Forge load, event calendar, injury/recovery evidence and the previous long-run finish. A title and a calendar date do not constitute a physiological gate.

## Evidence context

The Oct 2026 FORM database has incomplete filed longest-run evidence for several athletes; “not filed” is **not** “did not run.” A prospective 5,205-runner study found higher injury rates when single-run distance exceeded the individual's longest run in the prior 30 days by more than about 10%; this is a population risk signal, **not a rigid safe ceiling**. Source: *How much running is too much?*, *British Journal of Sports Medicine* 2025 (PMID 40623829). Observational half/full-marathon work supports adequate volume and longer endurance runs for performance but cannot prescribe a safe exact jump for any individual (PMID 32421886). These are reasons to verify training history and progress deliberately, not excuses to keep strong athletes permanently at short distances.
