# Homepage card pass · V7.1

Applied directly to the current integration `index.html` supplied in the card workpack.

## Outcome selector

The FORM and FORGE choices are no longer text sitting over faint screenshots. Each choice is now a two-part product panel:

- a dedicated copy region with its own hierarchy and CTA
- a separate visual stage with a real app screen
- no image may sit beneath or compete with the copy
- desktop uses a copy/visual split
- mobile stacks copy above the visual stage

The product images remain evidence, not wallpaper.

## FORM / FORGE plan facts

The three compressed columns now become a vertical plan receipt on mobile:

- label on the left
- value on the right
- Today receives a restrained product-accent marker
- no cramped mini-columns or awkward line breaks

Desktop keeps the compact three-part summary.

## Protected

The pass does not alter:

- the current positioning and copy polish
- the eight Library article links
- analytics `data-sf-event` hooks
- root-absolute asset paths
- footer depth links
- the current font doctrine
- FORM and FORGE chapter structure
