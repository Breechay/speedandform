## Why

Current server inspection shows form_game_week_for evaluates completion credit separately from the Towers; it preferentially uses the filed prescription version. form_true_easy prioritizes HR where available and uses pace/RPE fallbacks; a research pace-ceiling pass is not necessarily the same verdict. Inspect the canonical implementation and capture it, do not recreate an approximate parallel scorer.
