The ordinary run counts.

Not every useful run gives you a story to tell. It can still belong in the bigger picture.

By Brice Ikouebe · Revised September 17, 2026 · 1 min read

You went out, ran easily, and came home. No best time. No dramatic finish. Nothing that seems worth reporting.

It is easy to treat a run like that as the space between the sessions that matter. I would rather ask whether it did the job you needed it to do. Could you keep the effort comfortable? Did it fit the day? Did you leave room for the rest of the week?

A race gives training a date, but it cannot be the only reason a run feels worthwhile. Some days the satisfaction is in moving well. Some days it is the conversation. Some days it is simply having a practice that still fits your life.

That is not an argument for completing every run regardless of how you feel. A run you skip for a sensible reason is not a debt to pay back. It is an argument against turning every ordinary day into a test just to make it feel significant.

When you look back at the week, keep the quiet runs in the picture. They do not need a dramatic explanation to count.
