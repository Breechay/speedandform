## Claims rule

Never replace a pending result with a forecast. The page can say what the method asked and what was observed during training, but the transformation headline is written only from verified results.

If both athletes break 1:30, a secondary post-race campaign may truthfully use a line such as `Two runners. 1:40 → sub-1:30.` If outcomes differ, publish the two outcomes separately rather than compressing them into a cleaner story.

## Offer boundary

The paid value is the execution system rather than hiding a previously public calendar: pace setup rules, the full 15-week architecture, interpretation/progression rules, execution notes, race-week protocol, and coherent web/print delivery. Human review remains coaching and must not be implied by the self-directed product.
