Week 01 · Start here

Start with your current weights. Record the weight, reps and how many more good reps you could do. Do not test your maximum.

Week 02 · Repeat

Keep the same set counts. Add reps or the smallest weight only where last week’s sets were controlled.

Week 03 · Build

The first two exercises in Frame A and Frame B each have one extra set. Add it only if your running still feels normal. Otherwise keep Week 2’s set counts.

Week 04 · Keep building

Keep Week 3’s set counts. Improve the weight or reps without adding exercises.

Week 05 · Lighter week

Do the fewer sets shown this week. Keep your movements controlled and leave yourself fresh for running.

Week 06 · Review

Return to Week 4’s set counts only if you have recovered. Compare your weights and reps with Week 1. Do not test your maximum.

Week 1 · Start here

Start with your current weights. Record the weight, reps and how many more good reps you could do. Do not test your maximum.

Week 01 · Tuesday · 7 exercises

Frame A

Chest, shoulders, back and arms. Run first when practical.

  1. 01

    Barbell Floor Press

    4 sets · 8–12 reps

    Rest 90 sec between sets

    Use your current working weight. Keep each repetition controlled.

    How hard?

    Finish each set with about 3 good reps left.

  2. 02

    1-Arm Kettlebell Row

    4 sets · 10–15 reps per side

    Rest 75 sec between sets

    Keep your trunk still. Pull without rotating.

    How hard?

    Finish each set with about 3 good reps left.

  3. 03

    Half-Kneeling 1-Arm Kettlebell Press

    3 sets · 8–12 reps per side

    Rest 75 sec between sets

    Stay tall. Keep your back from arching.

    How hard?

    Finish each set with about 3 good reps left.

  4. 04

    Plate or Kettlebell Lateral Raise

    3 sets · 12–20 reps

    Rest 60 sec between sets

    Use your lightest plate or kettlebell so your shoulders do the work.

    How hard?

    Finish each set with about 3 good reps left.

  5. 05

    Rear-Delt Row

    2 sets · 12–15 reps

    Rest 60 sec between sets

    Keep your elbows wide and your body still.

    How hard?

    Finish each set with about 3 good reps left.

  6. 06

    Barbell Curl

    2 sets · 10–15 reps

    Rest 60 sec between sets

    Keep your hips still. Lift without swinging.

    How hard?

    Finish each set with about 3 good reps left.

  7. 07

    Close-Grip Push-Up

    2 sets · 8–20 reps

    Rest 60 sec between sets

    Keep the repetitions controlled. Stop before failure.

    How hard?

    Finish each set with about 3 good reps left.

Week 01 · Thursday · 5 exercises

Lower + Core

Legs, calves and core. Check the running session before you start.

Before you start

Do the full session only if you have recovered from Tuesday and today’s run is easy.

If today has intervals, a tempo run or hill repeats, do only the calf raise, suitcase march and side plank, or skip strength. Do not move missed work to Friday or Saturday.

  1. 01

    Split Squat

    3 sets · 8–12 reps per side

    Rest 90 sec between sets

    Raise your rear foot only if you have a stable surface. Keeping it on the floor is fine.

    How hard?

    Finish each set with about 3 good reps left.

  2. 02

    Barbell Romanian Deadlift

    3 sets · 8–12 reps

    Rest 90 sec between sets

    Lower the weight under control.

    How hard?

    Finish each set with about 3 good reps left.

  3. 03

    Single-Leg Calf Raise

    2 sets · 12–20 reps per side

    Rest 60 sec between sets

    Use your full range. Add kettlebell weight only while you can keep that range.

    How hard?

    Finish each set with about 3 good reps left.

  4. 04

    Suitcase March

    3 sets · 30–45 sec per side

    Rest 45 sec between sets

    Hold the kettlebell at your side without leaning.

  5. 05

    Side Plank

    2 sets · 30–45 sec per side

    Rest 45 sec between sets

    Keep a straight line from shoulder to ankle.

Week 01 · Sunday · 8 exercises

Frame B

Back, chest, shoulders and arms. Start after you have recovered from Saturday’s long run.

  1. 01

    Barbell Bent-Over Row

    4 sets · 8–12 reps

    Rest 90 sec between sets

    Keep your torso at the same angle. Use your current working weight.

    How hard?

    Finish each set with about 3 good reps left.

  2. 02

    Barbell Floor Press or Push-Up

    4 sets · 8–15 reps

    Rest 90 sec between sets

    Choose the floor press or push-up, using the option that works your chest with the equipment you have.

    How hard?

    Finish each set with about 3 good reps left.

  3. 03

    Kettlebell Pullover

    3 sets · 10–15 reps

    Rest 75 sec between sets

    Keep your ribs still as you reach. Avoid turning the movement into a triceps extension.

    How hard?

    Finish each set with about 3 good reps left.

  4. 04

    1-Arm Kettlebell Press

    3 sets · 8–12 reps per side

    Rest 75 sec between sets

    Keep each repetition controlled, especially after Saturday’s long run.

    How hard?

    Finish each set with about 3 good reps left.

  5. 05

    Rear-Delt Row

    3 sets · 12–15 reps

    Rest 60 sec between sets

    Keep your elbows wide and your body still.

    How hard?

    Finish each set with about 3 good reps left.

  6. 06

    Barbell or Kettlebell Shrug

    2 sets · 10–15 reps

    Rest 60 sec between sets

    Pause at the top. Do not roll your shoulders.

    How hard?

    Finish each set with about 3 good reps left.

  7. 07

    Barbell Curl

    2 sets · 10–15 reps

    Rest 60 sec between sets

    Keep your hips still. Lift without swinging.

    How hard?

    Finish each set with about 3 good reps left.

  8. 08

    Close-Grip Push-Up

    2 sets · 8–20 reps

    Rest 60 sec between sets

    Keep the repetitions controlled. Stop before failure.

    How hard?

    Finish each set with about 3 good reps left.

Weights, equipment and progression

Use the equipment you have.

Your adjustable kettlebell, small barbell and plates, mat and bodyweight. No bench is required.

Choose a weight you can control.

Use your current working weights. Record the weight, reps and how many more good reps you could do. Do not test your maximum. Open “How hard?” under an exercise for the number of good reps to leave.

When to add weight.

When every set reaches the top of its rep range with good form and about two good reps left, add the smallest available weight next time.

If your equipment cannot go heavier, use only a change in reps, tempo or exercise variation that Brice has given you.

Keep your running feeling normal.

Keep to the three sessions. Do not add a fourth day, bonus sets or extra exercises.

If strength keeps making your main runs harder for more than a week, reduce the strength work with Brice before changing the running.
