System rule

Running gets veto power.

If FORGE begins degrading Tuesday/Thursday/Saturday running for more than one week, reduce FORGE volume first. The strength plan exists to make a better athlete, not to win an argument with the running plan.

Weekly priority

Thursday is earned.

Tuesday owns the primary running question. Thursday strength serves the week only when Tuesday is absorbed; a full FORM Thursday workout and a full lower-body Forge session are not automatically stacked. Missed support is not debt.
