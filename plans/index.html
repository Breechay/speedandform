Plans

See how the work builds.

Training is an argument made over time. Each block starts with what you can already do, asks for one new thing, and builds on what the work establishes. Some plans are open; others let you preview the work before you buy the complete block.

How to use these
01

Practise how you run.

Your form is part of the training. Establish the one or two cues worth practising inside the block.

02

Run the progression.

Each session has a job. The next ask builds on what the previous work was meant to establish.

03

Let evidence decide.

If the work says something different than the plan expected, change the prescription rather than forcing the story.
