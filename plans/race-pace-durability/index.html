About this plan

Sub-1:30 is a durability demand.

You do not need to prove 6:52/mi for one mile. You need it available for 13.1.

This published sub-1:30 version uses 6:30–6:45/mi for race-pace work. The band stays fixed while uninterrupted distance grows. Individual assignments in the study can change with the athlete’s response.

Before you start

Not a beginner plan.

You should already be comfortable training six days per week, running around 45 miles per week, and completing a 12-mile long run. This block develops race-pace durability. It does not build the base from zero.

Sub-1:30 pace

1:29:59 = 6:52/mi · 4:16/km

Key work sits at 6:30–6:45/mi to create margin above goal pace.

The pace does not get faster every week. The distance you can hold continuously grows across the block.

5 → 6 → 8 → 12 continuous miles.
