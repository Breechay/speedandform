01 · The cost of pace

THE PACE STAYS THE SAME.
THE COST RISES.

6:35/mi on fresh legs can feel cheap. An hour later, the same 6:35 can be expensive.

Durability is how long you can keep the same pace from getting expensive.

The output is external. The cost is individual.

The question

How long can the same output stay economical?

Getting to a pace and keeping it are different problems. The same pace can cost two runners different amounts. It can even cost the same runner more an hour later.

Same output.
Rising price.
6:35/mi · held constant

The line is conceptual for now. Once enough paired evidence exists, José and Hope can each carry their own cost trace at the same target pace.

What running durability actually means

Three lenses

Different ways of watching the same pace get more expensive.

Mechanical

More work for the same velocity.

Your stride can get shorter, contact with the ground can get longer, and the muscles can do more work to hold the same speed.

Metabolic

The internal demand rises.

Heart rate and oxygen demand can rise even when the pace on the watch does not move.

Control

The same movement gets harder to hold together.

The same rhythm can take more concentration and coordination to hold together as fatigue builds.

SAME PACE. HIGHER PRICE.Mechanical, metabolic and control are three views of the same problem: the runner is producing the same thing while it asks more from them.
[01]Running economy and mechanics can deteriorate during prolonged running even when speed is held constant.What the literature suggests
Unhjem (2024) reported rising oxygen cost after prolonged running, with smaller deterioration in trained runners. Trowell, Kenneally-Dabrowski & Bonacci (2024) reported fatigue-related biomechanical changes including increased ground-contact time at consistent speeds. THE NUMBER IS NOT THE METHOD

YOUR PACE DOES NOT HAVE TO BE 6:30.

José is working at 6:30–6:45. Hope is now working at 6:45–7:00. Your pace might be 9:00, 8:00 or 7:00. The number is not the method: choose a pace you can already reach, then teach yourself to stay there longer and with less friction.

KEEP THE PACE SUBMAXIMAL

KEEP A CEILING
ABOVE IT.

Progress threshold time and continuity so race pace keeps sitting below the athlete’s sustainable ceiling. Faster work supports the spine; it does not replace it.

CHANGE THE CONTEXT

FRESH ACCESS IS
NOT LATE ACCESS.

Eventually you have to ask for the pace after you have already been running for a while. Hitting it fresh and finding it on tired legs are not the same skill.

06 · The experiment

SAME METHOD.
TWO PACES.
ONE SYSTEM.

No single workout solves this.

The big race-pace sessions are only the visible part. Easy running keeps the aerobic floor underneath them. Faster work keeps a ceiling above them. Long runs add time and fatigue. The race-pace sessions teach you to hold the specific speed.

THE FLOOREASY RUNS + LONG RUNS

The quality days are not the whole program. Endurance is what lets you absorb them, repeat them, and still have something left when the run gets long.

Tuesday

Race-pace specificity

Touch the pace, repeat it, then ask for longer stretches without a break.

Thursday

Ceiling progression

Progress threshold time and continuity so race pace keeps sitting below the athlete’s sustainable ceiling. Faster work supports the spine; it does not replace it.

Saturday

Durability context

Build endurance first. Later, ask for race pace near the end and see what is still there.

The continuous ask

Each athlete’s band stays fixed while the uninterrupted exposure grows: José 6:30–6:45/mi, Hope 6:45–7:00/mi. The weeks between the big asks build the system instead of testing it every Tuesday.

Start · Settle · Hold · Finish

Pacing is part of the durability question. From the broken reps onward, practise entering the assigned band without attacking it, settling, holding and finishing with control.

In each athlete’s read, compare the opening split with the middle and finish. Preserve any correction, effort and reserve. An aggressive opening followed by a fade is different evidence from an evenly paced session that becomes unsustainable.

When a short section is run without pace feedback, record the intended band and actual splits. No blind-pacing result is claimed until it has been practised and recorded. The race line will be set from the work they actually complete.
