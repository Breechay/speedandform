THE PRACTICE

RUNNING IS
A SKILL.

“It really taught me how to not push, just lightly increase cadence and stride.”

The goal is not to push harder every time. The goal is to run fast with less wasted effort. A golfer practices a swing. A swimmer practices a stroke. Runners can practice how they move too.

THE INSTRUMENT

CREATE
MORE ROOM
ABOVE IT.

Think of it this way: if 6:00 pace is close to your limit, it feels expensive. If you become capable of running faster than that, 6:00 can start to feel more normal. That extra room is what we are trying to build.

TAKE THE QUESTION · NOT THE NUMBERS

HOW TO USE
THE IDEA YOURSELF.

Do not copy their paces or assume you need the same six weeks. Copy the idea instead.

01FIND A CONTROLLED FAST PACE.

Pick a pace you can repeat without hanging on for dear life.

02MAKE IT LAST LONGER.

Before making it faster, see if you can hold the same pace for longer.

03KEEP SOME SPEED ABOVE IT.

Touch some faster running so your Tuesday pace is not the fastest thing you ever do.

04KEEP EASY RUNNING EASY.

Keep easy days easy and keep your long run. Faster work does not replace endurance.

05REPEAT THE SAME ASK.

Repeat the same workout later. If it feels easier or stays smoother, that matters even if the pace did not change.
