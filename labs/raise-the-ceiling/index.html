THE PRACTICE

RUNNING IS
A SKILL.

“It really taught me how to not push, just lightly increase cadence and stride.”

The goal is not to push harder every time. The goal is to run fast with less wasted effort. A golfer practices a swing. A swimmer practices a stroke. Runners can practice how they move too.

DO NOT COPY THEIR PACES

Simon is working around a 6:00/mi direction. Lisa is around 7:00–7:10/mi. Those are their numbers, not yours. Thursday is different: both athletes get the same FORM track target, and we record what each can actually do. Speed Demons and the other named sessions are fixed standards. When a session returns, we compare each athlete with their earlier attempt.

TAKE THE METHOD · NOT THE PACES

HOW TO USE
THE IDEA YOURSELF.

Do not copy their paces. Copy the structure.

01FIND A CONTROLLED FAST PACE.

Choose a pace you can repeat without panic.

02MAKE IT LAST LONGER.

Extend the duration before asking it to get faster.

03KEEP SOME SPEED ABOVE IT.

Touch faster running so Tuesday is not your ceiling.

04KEEP EASY RUNNING EASY.

Easy days and the long run keep the endurance underneath.

05REPEAT UNTIL THE SAME ASK COSTS LESS.

Run the same ask again. Lower cost is progress.
