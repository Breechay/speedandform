The method.

Build the athlete, then test the race.
  1. Establish the record. Confirm identity, format, timing boundaries and current running evidence. A similar name is not an identity match.
  2. Find the pattern. Look at runs, station execution and transitions together. Ask for the athlete's account before assigning a cause.
  3. Choose one comparison. Station pacing, break structure, load reserve, movement economy, opening run or Roxzone behaviour.
  4. Retest under comparable conditions. Keep prescription, conditions and outcome attached to the same record. Save a new record for each retest.
  5. Update the work. Keep what reduces total cost without degrading standards. A single good trial is provisional.
Turn a pattern into a test.
  • Fresh running improves; race running does not: investigate station execution, pacing, timing and fatigue before adding more speed work.
  • One post-station run is repeatedly slower: compare controlled station efforts followed by the same measured run; inspect posture and breathing.
  • Long station with stable running: inspect technique, pauses, strength reserve and no-reps. Running-first does not mean ignoring a large station opportunity.
  • Late fade: compare opening pace and accumulated workload. The final run may have different timing boundaries; verify before attributing it to lunges.
  • Slow wall balls: collect set sizes, rest duration and no-reps; compare sustainable breaks after matched prior work.
  • Large Roxzone time: inspect route, walking, congestion and preparation. Not all transition time is avoidable.
Use the numbers honestly.

Race = runs + stations + transitions + non-overlapping penalties

Running gap = measured HYROX pace − threshold pace

Velocity retention = threshold pace ÷ HYROX pace × 100

Both paces must use the same units. Retention is a descriptive ratio, not a validated HYROX score or a requirement to reach 100%. Threshold protocol, test freshness and measured distance affect it. No beginner/elite bands or fixed 10K-to-HYROX conversion are built in.

Station savings must be compared with the next run and later costs. A following-run gap is not an isolated measurement of “station tax.” Even splits are not inherently optimal when timing segments differ.

Race sequence and rules.

Singles follows eight run–station pairs: SkiErg, sled push, sled pull, burpee broad jumps, row, farmer's carry, sandbag lunges, wall balls. Use the event's current official HYROX rulebook for exact standards, loads and penalties. Do not copy Open prescriptions into Pro, Doubles or an adapted simulation without checking them.

This instrument is a FORM coaching framework, not an official HYROX product. Rules and physiological assumptions are not inferred from a result aggregator.
