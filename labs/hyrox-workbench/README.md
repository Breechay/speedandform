# FORM HYROX workbench

A coaching notebook at /labs/hyrox-workbench/. Save keeps records in this browser; Export/Import transfers JSON. No Console or cloud account sync. Keep athlete exports outside this public repository.

Uses the existing local Inter font, dark canvas, wide spacing and evidence hierarchy from the study family. Phone split entry stacks into labeled pairs. A portable HTML export embeds its font and script.

Validation: `node labs/hyrox-workbench/workbench.test.cjs`. Covers duration parsing, blank versus zero, complete totals and measured-distance pace/retention. Static checks cover field IDs and phone entry labels. Browser acceptance remains open because local file navigation was blocked; no workaround attempted.

The single work register and publication state live in [FORM-ROADMAP](../../docs/roadmap/FORM-ROADMAP.md). No fixed threshold conversion, elite retention bands, automatic prescription or causal station-tax diagnosis. No real athlete data is seeded.
