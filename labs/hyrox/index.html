01 · PrimerKnow exactly what the athlete is solving.

The race,
stripped down.

HYROX Singles is eight 1 km runs interrupted by eight fixed stations in a fixed order. Open vs Pro changes load; Pro is a division, not an earned professional rank.

Run. Complete the station. Find your running rhythm again. That is the FORM lens: train the whole race, including what happens between tasks.

Open, Pro and Elite

Open and Pro use different prescribed loads. Pro entry is not an earned professional rank. Elite racing has a separate qualification system. Confirm the athlete’s event and division, then check the official rulebook and qualification rules before prescribing. This page does not maintain current ranking cutoffs.

02 · DoctrineThe FORM way of seeing the race.

Four rules
to race by.

A faster station helps only if the seconds saved outweigh the cost elsewhere in the race.

01 · Clear

Clear the station cheaply.

Move efficiently at an effort you can afford. Test whether going faster saves time across the station and the running that follows.

02 · Return

Return to running immediately.

Leave the station and settle back into a sustainable rhythm. Watch how long breathing, posture and pace take to recover.

03 · Own

Own the repeatable pace.

Choose a pace you can return to across all eight runs. The first kilometer should support the finish.

04 · Spend

Spend more only when the race allows it.

As the finish approaches, judge what you can afford. On wall balls, use what remains while keeping valid reps and manageable breaks.

03 · ModelTurn the race into quantities you can test.

The
equations.

These are coaching instruments, not validated HYROX scoring systems. They force clean questions and make trade-offs visible.

Race time = runs + stations + Roxzone + penalties
Start here. Add each component once. Do not add penalties again if they are already included in the splits. Effort in one task can change the cost of later tasks.
Pair cost = station + next run
Use pairs. If a 10-second faster sled produces a 25-second slower next kilometer, it was a bad trade. Wall balls are different because there is no following run.
Run gap = HYROX pace − threshold pace
Positive means slower. Compare current benchmarks and measured run distances. This gap (sometimes called “Run Tax”) describes a difference; it does not isolate station fatigue.
Retention = VHYROX ÷ VThreshold × 100
Use velocity for percentages. Use paces in the same units: threshold pace ÷ HYROX pace × 100. This is a descriptive comparison, not a validated score or a target to force toward 100%.
Late change = late pace − early pace
Describe durability. Compare Runs 6–8 with Runs 1–3 using measured distances and comparable timing boundaries. A slowdown is a question to investigate, not a cause.

Three references, three different tasks.

A current 10K is a running benchmark. Threshold depends on its test method. HYROX adds station work and transitions. There is no fixed seconds-per-kilometer conversion here: choose a provisional pace, test it in measured station–run work, and revise it from the athlete’s response.

04 · PacingProtect the race that still remains.

Spend by
position.

“80% at every station” is too crude. The optimal station effort changes with the athlete, the station and how much race is left.

Stations 1–3

Cheap.

Controlled enough that the athlete can return to run pace quickly. Avoid ego spending while seven, six or five runs still remain.

Stations 4–6

Efficient.

Maintain race state. Rhythm and technique matter more than dramatic station wins.

Station 7 + Run 8

Controlled finish.

Choose an effort that lets you complete the final run and wall balls well. More aggression is useful only when it reduces the combined time.

Station 8

Finish.

No Run 9 exists. Protect movement standards, then spend what is left. Break strategy should prevent no-reps and involuntary chaos.

The governing rule

Choose the effort that improves the total race. A small loss on the next task can be worthwhile if the saving is larger. Test the trade-off.

05 · StationsWhat to watch before you prescribe.

What to watch
at each station.

Technique matters, but the coaching question is broader: what did this station cost the athlete, and why?

01 · SkiErgEarly control

Do not race the machine.

Watch stroke rate, length, trunk contribution and breathing. Fresh athletes can overspend here without realizing it.

Coach: choose an output that keeps Run 2 cheap.

02 · Sled pushStrength reserve

Avoid the grind.

Watch continuous movement, traction, torso angle, hip height and whether the athlete turns race weight into a near-max effort.

Coach: make the load feel routine through real strength.

03 · Sled pullTechnique + grip

Move the rope, not just the arms.

Footwork, rope organization and body position can waste or save large amounts of energy.

Coach: efficient rhythm first, then speed.

04 · Burpee broad jumpsSystemic fatigue

Watch the race change.

Watch floor time, jump length, breathing and pauses. Compare these with the next run; appearance alone cannot identify a physiological threshold.

Coach: rhythm that survives the following run.

05 · RowOutput + breathing

Make efficiency visible.

Record split pace, stroke rate, technique and breathing together. Do not assume the row is recovery: check what it costs the next run.

Coach: technical output, not violence.

06 · Farmers carryGrip + trunk

Keep the gait.

Watch shoulder elevation, torso lean, drops and stride shortening. A strong athlete should make the carry visually uneventful.

Coach: enough grip and trunk reserve that running shape survives.

07 · Sandbag lungesRun 8 tax

The final running test.

Pelvic control, knee tracking, trunk angle and pauses matter because the next task is the last kilometer.

Coach: train the transition, not lunges in isolation.

08 · Wall ballsNo downstream run

Break on purpose.

Set size, rest duration, no-reps and squat/throw economy tell you whether the finish was planned or became survival.

Coach: sustainable sets until the finishing point allows the athlete to empty.

06 · BuildDevelop capacity before adding noise.

Build the
athlete.

Do not confuse HYROX-looking workouts with HYROX development. The athlete needs a bigger engine, bigger reserve and the skill of returning to pace.

01

Running engine.

Threshold, economy, repeatable speed and enough aerobic volume that target pace is not already expensive before the first station.

02

Strength reserve.

Build squat, hinge, single-leg, press, pull and carry capacity where assessment shows a need. Then test whether that strength makes race work easier.

03

Return-to-run skill.

Controlled station → measured run. Teach posture, breathing and cadence to reappear quickly. Progress the cost only when the pace survives.

Fresh runningHYROX runningRead
ImprovesImprovesBoth improved. Check repeatability before progressing.
ImprovesStallsInvestigate station execution, strength reserve, pacing, transitions and accumulated fatigue before adding more speed.
StableImprovesInvestigate better pacing, technique or conditions. The result improved; the cause still needs checking.
StallsStallsCheck training exposure, recovery, test timing and measurement noise before changing the block.

General strength vs HYROX specificity

Specific work should test transfer, not replace development. With enough time before the race, build real strength while keeping a small HYROX dose. As the race approaches, increase station-specific expression and full-sequence work.

07 · ObserveWhat to capture in a simulation.

Watch what
changes.

Do not write “looked tired.” Establish the athlete's normal mechanics early, then record the exact change and when it appears.

Runs 1–8 — split, measured distance/timing boundary, first 200–300 m after each station.
Stations 1–8 — split, planned vs involuntary breaks, no-reps, technique and load.
Roxzone — walking, setup, hesitation, congestion and avoidable dead time.
Movement baseline — cadence, posture, arm carriage, stride length, breathing, head position.
First visible change — what changed first, not just when pace slowed.
Race inflection — record where a meaningful change appeared, if one did. Do not force a turning point into every race.

Save time
across the pair.

Station speed is useful only if the athlete can afford it.

14 · MethodReturn here when the answer feels too easy.

The
method.

The race is standardized. Your interpretation still has to be earned athlete by athlete.

Build the athlete, then test the race.
  1. Establish the record. Confirm identity, format, timing boundaries and current running evidence.
  2. Find the pattern. Look at runs, stations and transitions together. Ask for the athlete's account before assigning a cause.
  3. Choose one comparison. Station pacing, break structure, load reserve, movement economy, opening run or Roxzone behaviour.
  4. Retest under comparable conditions. Keep the prescription and outcome attached to the same record.
  5. Update the work. Keep what reduces total cost without degrading standards.
Turn a pattern into a test.
  • Fresh running improves; race running does not: investigate station execution, pacing, timing and fatigue before adding more speed work.
  • One post-station run is repeatedly slower: compare controlled station efforts followed by the same measured run.
  • Long station with stable running: inspect technique, pauses, strength reserve and no-reps.
  • Late fade: compare opening pace and accumulated workload before blaming the immediately preceding station.
  • Slow wall balls: collect set sizes, rest duration and no-reps; compare sustainable break structures after matched prior work.
  • Large Roxzone time: inspect route, walking, congestion and preparation.
Use the numbers honestly.

Race = runs + stations + transitions + non-overlapping penalties

Run tax = measured HYROX pace − threshold pace

Velocity retention = threshold pace ÷ HYROX pace × 100

Retention is descriptive, not a validated HYROX score. Threshold protocol, test freshness and measured distance affect it. A following-run gap is not isolated proof of “station tax.”

Rules, divisions and rankings change.

Singles follows the eight run–station pairs above. Use the current official HYROX rulebook for exact loads, movement standards and penalties, and the official Elite qualification page for current ranking rules.
