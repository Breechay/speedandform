01 · PrimerKnow exactly what the athlete is solving.

The race,
stripped down.

HYROX Singles is eight 1 km runs interrupted by eight fixed stations in a fixed order. Open vs Pro changes load; Pro is a division, not an earned professional rank.

Run. Complete the station. Find your running rhythm again. That is the FORM lens: train the whole race, including what happens between tasks.

Open, Pro and Elite

Open and Pro use different prescribed loads. Pro entry is not an earned professional rank. Elite racing has a separate qualification system. 02 · DoctrineThe FORM way of seeing the race.

Four rules
to race by.

A faster station helps only if the seconds saved outweigh the cost elsewhere in the race.

01 · Clear

Clear the station cheaply.

Move efficiently at an effort you can afford. Test whether going faster saves time across the station and the running that follows.

02 · Return

Return to running immediately.

Leave the station and settle back into a sustainable rhythm. Watch how long breathing, posture and pace take to recover.

03 · Own

Own the repeatable pace.

Choose a pace you can return to across all eight runs. The first kilometer should support the finish.

04 · Spend

Spend more only when the race allows it.

As the finish approaches, judge what you can afford. On wall balls, use what remains while keeping valid reps and manageable breaks.

03 · ModelTurn the race into quantities you can test.

Make the numbers useful.

Five simple comparisons. Each answers a different coaching question.

01 · Total race time

Where did the time go?

Runs + stations + Roxzone + penalties

31:20 + 24:00 + 4:00 = 59:20

Count each component once; add only penalties not already included.

02 · Station + next run

Did the faster station actually help?

Pair cost = station time + following run time

2:30 + 4:15 = 6:45

Compare the combined cost. Wall balls finish the race; they have no following run.

03 · Run gap

How much slower was race running?

HYROX pace − current threshold pace

4:20 − 4:00 = +0:20/km

Use measured distances and comparable benchmarks. The gap describes a difference, not its cause.

04 · Velocity retention

How much running speed was retained?

Threshold pace ÷ HYROX pace × 100

240 ÷ 260 × 100 = 92.3%

Convert both paces to seconds in the same units. This is a comparison, not a score to force toward 100%.

05 · Late change

Did the running slow later?

Late pace − early pace

4:25 − 4:10 = +0:15/km

Compare distance-adjusted Runs 6–8 with Runs 1–3 and check timing boundaries.

Three references, three different tasks.

A current 10K is a running benchmark. Threshold depends on its test method. HYROX adds station work and transitions. There is no fixed seconds-per-kilometer conversion here: choose a provisional pace, test it in measured station–run work, and revise it from the athlete’s response.

04 · PacingProtect the race that still remains.

Spend by
position.

“80% at every station” is too crude. The optimal station effort changes with the athlete, the station and how much race is left.

Stations 1–3

Cheap.

Controlled enough that the athlete can return to run pace quickly. Avoid ego spending while seven, six or five runs still remain.

Stations 4–6

Efficient.

Maintain race state. Rhythm and technique matter more than dramatic station wins.

Station 7 + Run 8

Controlled finish.

Choose an effort that lets you complete the final run and wall balls well. More aggression is useful only when it reduces the combined time.

Station 8

Finish.

No Run 9 exists. Protect movement standards, then spend what is left. Break strategy should prevent no-reps and involuntary chaos.

The governing rule

Choose the effort that improves the total race. A small loss on the next task can be worthwhile if the saving is larger. Test the trade-off.

05 · StationsWhat to watch before you prescribe.

What to watch
at each station.

Technique matters, but the coaching question is broader: what did this station cost the athlete, and why?

01 · SkiErgEarly control

Win the race later.

Settle into long, efficient strokes and controlled breathing. The SkiErg should leave you ready for Run 2.

Coach: Practice output you can sustain without an expensive next run.

02 · Sled pushStrength reserve

Feel the legs. Protect the run.

Try planned checkpoints within each lane—thirds, for example. Continue farther when movement stays smooth; take a brief reset before you grind. Leg burn is feedback, not a lactate measurement.

Coach: Compare the push plus Run 3. More aggression is useful only if the combined result improves.

03 · Sled pullTechnique + grip

Fast through technique.

Organize the rope, use your feet and whole body, and keep a repeatable pull. Brief resets can help preserve the rhythm.

Coach: Increase speed without turning the pull into an all-out effort that damages Run 4.

04 · Burpee broad jumpsSystemic fatigue

Make the next rep look the same.

Use a repeatable jump length and cadence. Test a brief floor reset if it helps you avoid rushed, costly repetitions.

Coach: A half-second pause is a cue to test, not a requirement on every rep.

05 · RowOutput + breathing

Long stroke. Unhurried recovery.

Practice a lower stroke rate while holding a useful split. Drive effectively, then let the recovery stay relaxed. Lower cadence alone does not make rowing economical.

Coach: Record split, stroke rate and effort together; choose the rhythm that leaves a good next run.

06 · Farmers carryGrip + trunk

Brace. Move the feet.

Keep the trunk stable and your gaze on the route ahead. Take quick, controlled steps and plan grip resets when needed.

Coach: Race the carry if you can hold position and preserve the next run.

07 · Sandbag lungesRun 8 tax

Repeat the same good lunge.

Keep depth, step length and trunk position consistent. Raise the rhythm only while reps stay valid and Run 8 remains usable.

Coach: Do not assume slow and fast lunges cost the same. Compare lunges + Run 8 + wall balls.

08 · Wall ballsNo downstream run

Spend what is left.

Use planned sets and short, deliberate breaks. Increase the finish effort while maintaining valid reps.

Coach: No next run remains, but failed reps and forced long rests still cost time.

06 · BuildDevelop capacity before adding noise.

Build the
athlete.

Do not confuse HYROX-looking workouts with HYROX development. The athlete needs a bigger engine, bigger reserve and the skill of returning to pace.

01

Running engine.

Threshold, economy, repeatable speed and enough aerobic volume that target pace is not already expensive before the first station.

02

Strength reserve.

Build squat, hinge, single-leg, press, pull and carry capacity where assessment shows a need. Then test whether that strength makes race work easier.

03

Return-to-run skill.

Controlled station → measured run. Teach posture, breathing and cadence to reappear quickly. Progress the cost only when the pace survives.

General strength vs HYROX specificity

Specific work should test transfer, not replace development. With enough time before the race, build real strength while keeping a small HYROX dose. As the race approaches, increase station-specific expression and full-sequence work.

Build separately. Connect deliberately.

Build

Running + strength

Develop the running and train station technique on their own. Use fresh station work to learn load, rhythm and breaks.

Connect

One useful mixed session

For an athlete who tolerates it, start with one controlled station–run session per week. Progress only when it supports the rest of the training.

Rehearse

More specific near the race

The final four weeks can emphasize race order, transitions and the finish. Adapt to readiness and race date; keep recovery before race day.

EMOMs and AMRAPs can serve technique or conditioning. Select them for a specific purpose; completing more circuits is not proof of better race execution.

01 · One station. Two approaches.

Question: does a more controlled station improve the combined station + next run?

  1. Warm up. Choose one station, a repeatable load/distance and a measured 800 m run. Write down the recovery you will use between trials.
  2. Trial A: complete the station at your usual effort, then run 800 m at your working target. Record both times, breaks and effort.
  3. Trial B: repeat with a more controlled station effort. Keep load, distance and recovery the same.
  4. Compare the pair totals below. Repeat on another day with the order reversed before deciding that one approach is better.

Keep: the approach that repeatedly saves combined time with acceptable technique and effort. Change: one variable if the result is unclear.

Before you start

Warm up. Choose the sled/carrying loads, wall-ball reps and breaks, and recovery between blocks. Use the reference pace only if it suits this athlete. The original threshold example was 3:55/km.

The cue

Steady pressure. No repeated surges.

Aim to keep effort controlled and regain running rhythm promptly. Review heart rate alongside breathing, pace, technique and perceived effort. A perfectly flat HR trace is not the target; station demands differ.

How to read the comparison

Fresh time already exceeds the race budget: revisit the target or develop the station. Fresh time is below it: there is time allowance, but no proof the target will survive the race.

Example: a 2:40 fresh station against a 3:00 budget leaves 0:20 allowance. It does not establish a universal 20-second fatigue cost. Repeat under controlled station–run conditions, then confirm in a longer sequence.

Keep sled and turf conditions especially consistent. A faster isolated time is useful only if its technique and effort transfer to the race.

07 · ObserveWhat to capture in a simulation.

Watch what
changes.

Do not write “looked tired.” Establish the athlete's normal mechanics early, then record the exact change and when it appears.

Runs 1–8 — split, measured distance/timing boundary, first 200–300 m after each station.
Stations 1–8 — split, planned vs involuntary breaks, no-reps, technique and load.
Roxzone — walking, setup, hesitation, congestion and avoidable dead time.
Movement baseline — cadence, posture, arm carriage, stride length, breathing, head position.
First visible change — what changed first, not just when pace slowed.
Race inflection — record where a meaningful change appeared, if one did. Do not force a turning point into every race.

Measurement and race rules

Use current benchmarks and measured distances. A split points to a question; it does not prove a cause. Count penalties once.

HYROX pacing questions
What pace should I use for my first HYROX?
Start with current running evidence, then test a pace you can repeatedly regain after stations. Use the budget calculator to check the full-race cost.
How much slower is HYROX than fresh running?
There is no fixed offset. Compare current benchmarks with measured race or simulation running under known conditions.
What is the Roxzone?
The transition area between the running course and stations. Include its time in your race budget.
Does this shortened simulation predict my finish?
No direct conversion is established. Use it to test control and transitions; estimate all full-distance race components separately.
