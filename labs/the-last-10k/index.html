01 · Teaching applied

THE REFERENCE SAYS WHAT TO DO.
THIS STUDY SHOWS WHAT HAPPENS.

Four lessons from the marathon reference become four concrete things we can watch in Hope and José.
Lesson 01 · Keep a ceiling

Faster work does not disappear.

Applied: W3 reopens aerobic power; later ceiling touches stay in the block when they do not compromise Saturday.

Lesson 02 · Move access later

Same capability. Harder moment.

Applied: W4 final 6 → W5 3 + 3 → W6 final 10K. The fast volume is not endlessly inflated; the context gets deeper.

Lesson 03 · Fuel the test

A bad fueling day is a bad durability test.

Applied: race-intent fueling begins with the marathon-specific long runs and gets filed beside the result.

Lesson 04 · Protect the opening

The first 20 miles write the last 10K.

Applied: the W6 Closing-10K run starts with 14–15 controlled miles. Donna uses the same logic over the full race.

03 · Two quiet weeks

RECOVER.
THEN RETURN.

No test belongs here. The first week absorbs Orlando. The second restores normal running so the Donna block starts from a body that is ready to train again.
Week 01 · Dec 06–12

RECOVER

Unload Orlando and the 15-week accumulation.

  • 4–5 running days maximum
  • ~24–30 miles or less if response asks for less
  • Easy only · no pace requirement
  • Race debrief captured
  • No long-run achievement to prove
Week 02 · Dec 13–19

RETURN

Restore rhythm without creating a new performance question.

  • 5–6 running days
  • ~34–40 miles
  • Easy frequency returns
  • Short strides or hills if comfortable
  • Relaxed 9–10 mile long run · no test

Four hypotheses · what we think before we know
01Can the pace still show up late?
02Can faster work stay available?
03Does patience early matter?

H01 · Late access

CAN IT STILL SHOW UP LATE?

If Act I establishes the reserve continuously, progressively increasing the running before it should preserve or improve access under accumulated load.

H02 · Ceiling preservation

CAN FASTER WORK STAY AVAILABLE?

Controlled threshold and aerobic-power performance should remain broadly stable through the marathon block without repeatedly degrading Saturday availability.

H03 · Restraint

DOES PATIENCE EARLY MATTER?

What the athlete spends before the decisive segment changes what remains available when the marathon becomes expensive.

H04 · Cost / absorption

DOES THE SMALLER TASK SETTLE?

After the principal Closing-10K exposure, a deliberately smaller late-reserve task should be completed without disproportionate cost or prolonged recovery.

What would change our mind · protocol commitments
H01 weakens ifLater placement repeatedly removes access.

The reserve becomes unavailable despite controlled openings, deliberate fueling and otherwise comparable conditions.

H02 weakens ifFaster performance deteriorates or repeatedly steals from Saturday.

Comparable threshold/aerobic-power work becomes materially harder or slower, or repeatedly degrades the governing Saturday question.

H03 weakens ifOpening cost has no useful relationship to what remains late.

Across comparable work, late availability varies independently of how conservatively the prior running was distributed.

H04 weakens ifThe reduced task still carries disproportionate cost.

The smaller W7 ask requires unusually high effort, the reserve disappears, mechanics materially deteriorate, or recovery remains impaired.
